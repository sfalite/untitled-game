# Chaos City.io development rules

Read `llms.txt` before changing SDK code. Keep `sim.ts` deterministic: no Date, timers, Math.random, network calls, DOM, or browser globals. Its Planck/Box2D physics is scaled at 32 px per metre and canonicalised every 100 ticks; player body-pose fingerprint and state/body handles must remain in sync. Keep renderer-only code under `client/`, use relative asset paths, preserve the current `game` slug, and keep touch controls. Keep the 43×35 player sprite native-sized and use a matching 43×35 oriented physics box. The source faces up, so the visual, hitbox rotation and hand-held weapon use `aimAngle + Math.PI / 2`; keep `aimAngle` separate from the physical `angle` returned by the prediction fingerprint. The fingerprint's x/y must be in game pixels, not Planck metres. Keep the tree sprite native 128×128 with matching static Box2D colliders, and make every prop fixture match its rendered bounding dimensions. Do not change the local audio mapping for AK-47/M249, M134 Minigun and Shotgun. Run `npx moddio test` after simulation changes and `npx moddio play --players 2` to inspect the browser experience before publishing.
