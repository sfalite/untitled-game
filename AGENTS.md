# Chaos City.io development rules

Read `llms.txt` before changing SDK code. Keep `sim.ts` deterministic: no `Date`, timers, `Math.random`, browser globals or network calls. The game uses Planck/Box2D through `@moddio/sim/planck`; coordinates are pixels, physics uses 32 pixels per metre, and the Planck adapter is canonicalized every 100 ticks. Preserve `predict: 'self'` unless an official SDK test demonstrates a safe reason to change it. Whole-world prediction previously caused remote-player snapping.

The player sprite is 43×35 and looks up by default. Render it and its held weapon with `aimAngle + Math.PI / 2`; bullets use `aimAngle`. Keep the player fingerprint's x/y in game pixels, not Planck metres. Tree artwork remains 128×128, while the trunk collision is a centered 15×15 circle (radius 7.5 px). Keep the city map and simulation collider geometry in sync. Preserve the unmarked roads and continuous cached floor rendering.

Inventory is five slots: `[Glock-17, AK-47, M249, M134 Minigun, Shotgun]` item IDs, with slot 5 initially empty hands. Crates can drop collectible guns; E picks up, G drops, and empty slots cause server-authoritative melee. Ordinary props have 20 HP and cars 200 HP. Keep every damage, pickup, drop, and bullet collision decision authoritative in `sim.ts`.

For responsive shooting, predict local audio and one world-space muzzle flash keyed by owner/token; visible projectiles come from the authoritative simulation to avoid duplicate provisional/authoritative bullets. The typed input includes `shotToken: u32`; every accepted authoritative bullet stores its client shot token and pellet index. A queued shot must never keep a world-space origin captured before a cooldown wait: when accepted, calculate the muzzle from the current authoritative player position and aim. Never move an in-flight bullet to the shooter's current muzzle. F4 collision debug must not draw a second bullet marker over the real projectile. Keep the same muzzle offsets and firing rules on client and sim. Seed the local shot-token baseline from the merged player returned by `mergeSelf`, because `state.players[game.player]` may not contain the self-predicted player. Capture short pointer clicks as one-shot input pulses, filter inventory clicks, and ensure each pulse is consumed once. Single-projectile guns follow the cursor exactly and shotgun pellets use the same deterministic fan on all clients. Do not add `inputLead: false` as a shortcut; SDK docs reserve it for games without local prediction.

Keep the current `game` slug in `moddio.json`, relative asset paths, responsive HUD and touch controls. Run `npx moddio test` and `npx moddio play --players 2 --seconds 8 --shots 3,5` after sim changes, then test a two-client browser session before publication. Do not claim official runtime validation if only local TypeScript/static checks were run.
